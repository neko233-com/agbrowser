在 `D:\Code\neko233-Projects\agbrowser` 从零建立 **agbrowser**：面向 AI Agent 的 Chromium 内核浏览器运行时。已发布至 GitHub 公开仓库 `neko233-com/agbrowser`。

### 核心技术决策（实测得出，非推测）

1. **不 fork Chromium**。本机无 Rust/cargo，编译 Chromium 需 ~100GB 磁盘 + 数小时，不可行。改为复用系统已装的 Chrome/Edge 可执行文件。

2. **必须用 Node 24 LTS**。Node 22 内置 WebSocket 在约 4MB 处卡死（4/6/8/16MB 全部 TIMEOUT），导致大页面快照与截图失败；Node 24 实测 16MB 无压力。

3. **Chrome 136+ 禁止在默认 user-data-dir 下开远程调试端口**（实测：默认目录无 DevToolsActivePort，非默认目录正常）。方案：用目录联接（junction）在 `%LOCALAPPDATA%\agbrowser\channels\<channel>\` 下链接真实 profile 与 Local State，浏览器读写的仍是原文件——Edge 的 Bookmarks 1.4MB / Login Data 983KB / Preferences 390KB 实测原样可见，**不复制、不解密、不导出、不修改真实 profile**。

4. **Chrome 137+ 移除了 `--load-extension`**。官方替代是 CDP 的 `Extensions.loadUnpacked` + `--enable-unsafe-extension-debugging`；走调试端口而非 pipe 可保持 `navigator.webdriver === false`。实测三个扩展均加载成功（ID: nkmkomaeaopfmmfkjiplbhaajlnaodgm / khodncbeheikgkmgaopiickbdlcaechn / idlcdmbjhdcllebjemipfpdadcngbloo）。

5. **纵向标签栏**：真实存储键为 profile `Preferences` 里的 `vertical_tabs.enabled = true`（同组含 `collapsed_state` / `uncollapsed_width` / `enabled_first_time`）。预置后 Chrome 启动即显示"标签页位置=纵向[S]"。Chrome 156 需 `VerticalTabs,TabStripUnification` 特性；Edge 156 已 GA。

6. **默认浏览器无法程序化设置**。Windows 2024-02 起的 `UCPD.sys` 驱动拦截所有 UserChoice 写入（实测 "Access is denied"，该键当前用户有 FullControl，故非权限问题而是驱动保护）。决策：**不修改系统安全配置**，改为注册 ProgID + 检测 UCPD + 引导用户在「设置→应用→默认网页浏览器」确认一次。

### 实现要点

- 零运行时依赖，仅用 Node 内置模块（WebSocket / fetch / node:sqlite）。
- 广告拦截双层：纯域名规则走原生 `Network.setBlockedURLs`（零 JS 开销），复杂规则才启用 CDP `Fetch`。
- 广告拦截器必须放行 `chrome-extension://` 等浏览器内部协议，否则会把自己的插件拦掉（实测 ERR_BLOCKED_BY_CLIENT）。
- 反检测层：消除自动化带来的可观测差异（navigator.webdriver、cdc_* 钩子、window.chrome、Permissions API、WebGL vendor），使页面对人与 Agent 表现一致。
- MCP：24 个 `browser_*` 工具，紧凑 a11y 快照（`@eN` 引用），实测一次页面读取仅数行而非数万 token。

### 踩过的坑（均已修复并有回归测试）

- WebSocket `message` 事件传的是 MessageEvent，必须取 `event.data`。为支持 removeEventListener 而绑定方法时曾丢失解包，导致所有 CDP 命令超时。
- `--enable-features` / `--disable-features` Chromium 只认最后一个，重复写会互相覆盖。
- ABP 规则选项分隔符是 `$` 不是最后一个逗号；字符类中 `-` `|` `,` 必须置于首位否则被当作范围运算符。
- 路径锚点规则需用 `$` 定位选项起点，否则 `||x^$script,third-party` 的选项被整体丢弃。
