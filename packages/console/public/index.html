快速开始

把 agbrowser 装进你的 AI 客户端：

agb install

单独启动一个会话：

agb launch --account chrome/Default

查看环境体检结果：

agb doctor

标签同步

Chrome 与 Edge 的账号可以互相同步标签页：

agb sync add chrome/Default edge/Default

同步规则也可以由 MCP 工具 browser_sync_add 创建。

说明

agbrowser 直接接管浏览器原生用户数据目录，因此密码管理器、收藏夹与厂商账号同步全部由内核原生完成，不做任何数据搬运或解密。

标签栏默认使用浏览器原生左侧纵向模式。
